# Glossary

| Term                 | Meaning                                                                                                                                    |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Account              | Container that owns a landlord's portfolio and its business records.                                                                       |
| Account owner        | User who created/owns an account and may manage its members and access.                                                                    |
| Member               | User who belongs to an account, either as its owner or by invitation. A user may belong to multiple accounts.                              |
| No access            | The member cannot use or view a specific application area.                                                                                 |
| Viewer               | A member who can view records in an assigned area but cannot change them.                                                                  |
| Editor               | A member who can view, add, change, and delete records in an assigned area.                                                                |
| Rentable room        | A landlord-named space within a property that can have its own contract and shares the property's address.                                 |
| Contract signer      | A person recorded as signing a rental contract; other household occupants are not signers.                                                 |
| Rent receipt         | A manually recorded cash payment that may be allocated across expected rent payments for a contract.                                       |
| Rent reduction       | A recorded non-cash reduction agreed for a specific expected rent payment, distinct from money received.                                   |
| Archived property    | An inactive, read-only property whose history is retained until restored, distinct from a soft-deleted property.                           |
| TEST                 | Isolated environment for integration, acceptance, and deployment verification.                                                             |
| PROD                 | Live production environment.                                                                                                               |
| Synthetic user       | Controlled test identity that uses the normal authentication flow and is not an authentication bypass.                                     |
| Affected app         | An app whose own inputs or dependent shared packages changed, as determined by the Nx project/task graph.                                  |
| Pre-release          | GitHub release created after successful TEST deployment and verification, before PROD promotion.                                           |
| Intentional rollback | An explicitly selected PROD deployment of an older tag previously deployed successfully to PROD, subject to database compatibility checks. |
